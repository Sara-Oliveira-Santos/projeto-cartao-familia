# Projeto Cartão Família 

Este é um projeto desenvolvido em **Python** com o objetivo de praticar lógica de programação, manipulação de listas, modularização (uso de funções) e validação de dados. O sistema simula o gerenciamento de um "Cartão Família", permitindo o controle de membros, validação de CPFs e operações de cadastro.

## Sobre o Desenvolvimento

Este projeto foi construído inteiramente com base em lógica própria e dedicação aos estudos de programação, servindo como um excelente exercício para fixação de estruturas de dados em Python.

## Funcionalidades

O sistema possui uma interface de linha de comando (CLI) com as seguintes opções:

* **Dados do Usuário:** Cadastro do responsável com validação de CPF (11 dígitos e algoritmo de validação matemática).
* **1 - Cadastrar CF:** Cadastro inicial dos membros da família (nome e CPF) associados ao responsável.
* **2 - Adicionar Membro:** Permite adicionar novos membros ao Cartão Família sem perder os dados anteriores.
* **3 - Retirar Membro:** Remove um membro específico da lista com base na numeração exibida.
* **4 - Visualizar Membros:** Mostra o responsável, a quantidade de membros e a lista de todos os integrantes com seus respectivos CPFs.
* **5 - Cancelar CF:** Limpa os dados e encerra o vínculo do cartão.
* **6 - Voltar ao Início:** Reinicia o sistema permitindo um novo cadastro.
* **7 - Fim de Processo:** Encerra a execução do programa.
